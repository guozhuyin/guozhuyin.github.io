# 注音的個人網站

[前往網站](https://guozhuyin.github.io/)

我是注音，國立中央大學網路學習科技研究所碩士畢業，從網頁與軟體開發、數位教育遊戲到 AI 互動系統，持續嘗試把技術用在實際的學習與使用需求中。這個網站整理研究與開發作品、求學經驗，以及科技學習和單車旅行的紀錄。

## 在這裡可以看到

- **研究與作品**：AI 數學解題系統、Unity 互動學習環境、教育遊戲與農作物影像辨識，記錄實作過程、本人分工、成果與反思。
- **關於注音**：從接觸電腦、刷機與命令列，到大學和研究所的學習經驗，也分享單車旅行與志工活動。
- **文章與觀察**：整理開發、科技與生活中的經驗，文章全文保留在[個人部落格](https://zhuyin.epizy.com/)。

網站提供繁體中文與英文、明亮與暗黑模式，支援手機與桌面閱讀。

持續學習，也持續記錄。
